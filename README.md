# Groww Business Analyst Assignment Website

This static website is structured as:
1. What was given — assignment questions, six source CSVs and revenue rules
2. Overall approach — data preparation, cohorts, analysis and validation
3. Q1 — problem, approach, solution, metrics, charts and business action
4. Q2 — problem, approach, model comparison, top-20 metrics, workflow and caveats
5. Q3 — problem, approach, channel table, charts, recommendation and limitations
6. Q4 — problem, approach, revenue mix, stress test and strategic next bet
7. Final recommendations and assumptions

## Deploy with GitHub Pages
1. Create a GitHub repository, e.g. `groww-assignment`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the public URL.

No framework, build command, API key or external library is required.
